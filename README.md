# AeroTouch-Surgical-Gesture-Controller
Touchless mid-air surgical display controller powered by MSP430F5529 &amp; ESP32-S3. Combines HC-SR04 presence wake-up (LPM3), dual bit-bang I²C VL53L0X ToF sensors, discrete MIMO EMA filtering, and native USB HID translation (91.67% accuracy, 2.17 ms latency).
